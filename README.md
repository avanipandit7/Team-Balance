# ⚖️ Team Balance

Team Balance is a **React + Firebase** project management app that helps teams track tasks, measure individual contributions, and prevent uneven workload distribution.

## 🚀 Features

- 🔐 Firebase Authentication (Login & Signup)
- 📋 Create, assign, and manage team tasks
- 🎯 Weighted task points (1–10) to measure contribution
- 📅 Deadline tracking with overdue alerts
- 📎 Upload evidence (files or links) when completing tasks
- 📊 Dashboard with contribution statistics and progress overview
- ☁️ Real-time task sync using Firestore

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend & Database:** Firebase Authentication + Firestore
- **Styling:** Custom CSS (Dark Theme)

## ⚡ Getting Started

```bash
git clone <repository-url>
cd team-balance
npm install
npm start
```

Add your Firebase configuration in `firebase.js` before running the app.

## 📌 Purpose

A simple and transparent collaboration tool that quantifies team effort, tracks accountability, and visualizes each member's contribution in real time.
