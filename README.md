# TEAMBALANCE 🚀

A modern team collaboration and task management application built with **React** and **Firebase**.

TEAMBALANCE helps teams assign tasks, track contributions, monitor deadlines, and visualize productivity with an interactive dashboard.

---

# ✨ Features

## 🔐 Authentication System
- User Signup & Login
- Firebase Authentication integration
- Email & password validation
- Secure logout functionality
- Persistent login sessions

---

## 📋 Task Management
- Create and assign tasks
- Add task weights (1–10 points)
- Set deadlines
- Mark tasks as completed
- Reopen completed tasks

---

## 📎 Evidence Upload System
Attach proof of work using:
- Links
- File uploads

### Supported File Formats
- JPG / PNG
- PDF
- DOC / DOCX

---

## 📊 Dashboard & Analytics
- Team contribution tracking
- Progress visualization
- Completion percentage analytics
- Contribution split charts
- Individual member statistics

---

## ⏰ Deadline Tracking
- Overdue alerts
- Due today reminders
- Upcoming deadline warnings

---

## 🎨 Modern UI
- Fully responsive layout
- Dark theme interface
- Smooth hover animations
- Clean dashboard design

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Firebase SDK
- Inline CSS styling

## Backend / Database
- Firebase Firestore
- Firebase Authentication
